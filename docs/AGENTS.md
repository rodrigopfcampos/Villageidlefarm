## Regras

1. **Contratos primeiro.** Tipos, erros, eventos e RPCs vêm de `@vif/shared`. Não declare cópias locais.
2. **Valor só no servidor.** Nada de calcular moedas, prontidão, bônus de carta ou estoque no cliente para decidir; só para prever/desenhar. Nada de `Date.now()` para decidir (o lint avisa).
3. **Toda mutação leva `requestId`** (`newRequestId()` de `core/ids.ts`).
4. **Moeda inteira.** Bônus fracionários com arredondamento estocástico.
5. **Use a mock para desenvolver.** `new MockApi({ clock: new FakeClock() })` nos testes; a mesma suíte de contrato (`mockApi.test.ts`, `mockApi.rules.test.ts`) deve passar contra a API real (A2/A4/A6).
6. **Arte gerada não se edita à mão** (`public/assets`, `shared/src/generated`). Troque a arte de origem e rode o pipeline.
7. **Nada de vender cartas aleatórias por dinheiro.** Cartas vêm só de jogar.
8. **Antes de entregar:** `pnpm typecheck && pnpm lint && pnpm test && pnpm build`.
9. **Branches:** `agent/<nome>`, merge por PR. Migrations com a faixa numerada do seu dono.
10. **Eventos novos** no bus: peça ao A0 para incluir em `ClientEvents`.

## Pontos de extensão deixados pela Fundação

- `FarmScene` (A3): mapa, overhead, `cameraController` (com `isDragging`) e `layoutDebug`. Recebe `{ loaded, layout }` do Boot. Use `getServices()` para `store`, `api`, `bus`, `layout`.
- `DEPTH` e `TEXTURE_KEYS` em `core/constants.ts` / `core/assets.ts`.
- `store.optimisticPlot()` / `store.optimisticItems()` devolvem a função que desfaz. `store.cards` (não usadas), `store.currentBuffs()`.
- `services.run(op, call)` publica `api:error` automaticamente. `startHeartbeat` já usa 1 min durante o evento.
- Regras puras em `@vif/shared`: `proratedBonus`, `cardDropChance`, `buildAlbum`, `nightEventEndsAt`, `localTime`…
- Prévia sem pipeline: `pnpm dev` e abra `http://localhost:5173/?dev-assets`.
